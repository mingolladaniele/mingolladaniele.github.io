### Gap critici homepage (dettaglio)

- **FCP** 3.0s — above target
- **LCP** 3.5s — above target
- Render-blocking CSS (~1.9s)
- Immagine profilo non WebP
- Navbar toggler senza nome accessibile
- Contrasto colori insufficiente (WCAG AA)
- Heading order non sequenziale
- Nessun `canonical`, `favicon`, `robots.txt`, `sitemap.xml`

### Gap design (pre-redesign, Hallmark)

- Struttura template AI probabile (hero centrato → 3 card skills uguali → projects grid → contact → footer)
- Palette Bootstrap blue generica; nessuno stamp macrostructure
- Font stack Inter/system sans senza token locked
- Gradient hero blu = tell slop (gate 2/7)
